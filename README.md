# SVE-simulation
This repository contains simulation code for stochastic Volterra equations (SVE).

In particular, I have implemented numerical simulations of SVE under both uniform (equidistant) sampling and non-uniform (non-equidistant) sampling schemes.
The simulations are carried out for different values of the Hurst parameter, namely
H = 0.1, 0.3, and 0.4 with 
$$
\theta_t = 1 + 0.5|W_t|
$$
